
# Sistema de Gestión Académica

## Descripción
Este proyecto consiste en una aplicación web para una institución
educativa. Su propósito es organizar algunas funciones relacionadas
con la gestión académica.

## Objetivo
Crear una interfaz web sencilla que permita iniciar sesión,
navegar por un menú principal y gestionar usuarios.

## Tecnologías utilizadas
- HTML: estructura de las páginas.
- CSS: estilos y diseño visual.
- JavaScript: validaciones, eventos y lógica de la aplicación.
- LocalStorage: almacenamiento de los usuarios en el navegador.

## Funcionalidades desarrolladas

### Inicio de sesión
- Formulario para ingresar usuario y contraseña.
- Validación de las credenciales de prueba.
- Mensajes de respuesta.
- Control de intentos fallidos.
- Acceso al menú principal cuando los datos son correctos.

### Menú principal
- Navegación entre las opciones disponibles.
- Acceso a la gestión de usuarios.
- Opciones para notas y asistencia, según la implementación actual.

### Gestión de usuarios
- Registrar usuarios.
- Mostrar la lista de usuarios.
- Editar usuarios.
- Eliminar usuarios.
- Guardar los datos en LocalStorage.
